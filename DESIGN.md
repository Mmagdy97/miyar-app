# Design: Gypsum & Ink
Quiet, precise work tool. Plaster ground (#F3EFE6), ink text (#1A2236), brick accent (#B5452B), 1px rules (#DAD3C2).
- Type: IBM Plex Sans Arabic + Inter; no letter-spacing in Arabic; tabular numerals.
- Radius 6/8/12; flat depth, crisp shadow only on overlays.
- KPIs: ruled figures strip (`.stat-grid`), not floating cards.
- Status: swatch chips (colour square + label).
- Landing: start-aligned, one idea per band, ruled cells; no eyebrow kickers.
- Motion: ease-out, <300ms, none on high-frequency actions.
- Dark: generated via `python3 scripts/gen-dark.py`.
